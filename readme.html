About the Project

What is Dog Vision?

Dog Vision is a deep learning project that tackles one of the more delightful challenges in computer vision: looking at a photo of a dog and knowing exactly what breed it is. It was built on the Kaggle Dog Breed Identification dataset — over 10,000 labelled images spanning 120 unique breeds, from Affenpinschers to Yorkshire Terriers.

The model learns to tell apart breeds that look strikingly similar — like the Siberian Husky and the Alaskan Malamute — by identifying subtle differences in facial structure, coat texture, and body proportion. The secret ingredient? Transfer learning. Rather than training a deep neural network from scratch (which would require far more data and compute), the model borrows the visual knowledge baked into MobileNet V2 — a network pre-trained on over a million images — and applies it to the new task of dog breed classification.

"Instead of learning from zero, the model stands on the shoulders of giants — leveraging millions of pre-learned visual patterns and directing them toward a focused new problem."

The result is a compact, fast model capable of classifying 120 breeds with meaningful confidence, deployable on mobile or web.

The ML Pipeline

From Raw Photos to Breed Predictions

Hover over each step to explore the details.

01
Data Ingestion & Labelling
The Kaggle Dog Breed Identification dataset is loaded: 10,357 labelled training images and 10,357 unlabelled test images across 120 unique breeds. Labels are one-hot encoded into binary vectors for multi-class classification.
pandas · numpy · os
02
Image Preprocessing
Each image is decoded from JPEG, resized to 224×224 pixels, and normalised to a [0, 1] float tensor. Images are batched using tf.data for efficient GPU-accelerated data pipelines — no bottlenecks during training.
tf.data · tf.image
03
Transfer Learning with MobileNet V2
A frozen MobileNet V2 feature extractor from TensorFlow Hub serves as the backbone. Its weights — learned from ImageNet — are reused directly. Only the new classification head (Dense 120, softmax) is trained from scratch on our dog breed data.
tensorflow_hub · hub.KerasLayer
04
Training with Early Stopping
The model trains on an 80/20 train/validation split. An EarlyStopping callback monitors validation accuracy (patience=3), halting training when the model stops improving. TensorBoard logs track loss and accuracy curves in real time.
EarlyStopping · TensorBoard · Adam
05
Full Dataset Retraining
After validating the architecture on a 1,000-image subset, the model is retrained on the complete dataset to maximise performance before making final Kaggle test predictions.
full_model · model.fit()
06
Prediction & Submission
The trained model generates breed probability vectors for all 10,357 test images. These are written to a Kaggle-format CSV (full_model_predictions.csv) with one probability column per breed. Custom images from the real world are also tested — including the German Shepherd pup below.
model.predict() · pandas · CSV export
Model Architecture

A Lean, Powerful Stack

The architecture is intentionally minimal. Transfer learning means we don't need a massive custom network — we bolt a classification head onto an already-powerful feature extractor.

🔗

Input Layer

224 × 224 × 3 normalised float tensors. Images are preprocessed into batches via tf.data before reaching the model.

🧠

MobileNet V2 Backbone

Pretrained on ImageNet via TF Hub. Weights are frozen — the backbone acts purely as a visual feature extractor, not a trainable component.

🎯

Classification Head

A single Dense(120, activation='softmax') layer maps the 1280-dim MobileNet feature vector to breed probability distributions.

⚡

Training Config

Adam optimiser, categorical crossentropy loss, validation accuracy monitoring, EarlyStopping (patience=3), TensorBoard callbacks.

# Model architecture model = tf.keras.Sequential([ hub.KerasLayer( MODEL_URL, trainable=False # frozen backbone ), tf.keras.layers.Dense( len(unique_breeds), activation="softmax" ) ]) model.compile( loss="categorical_crossentropy", optimizer=tf.keras.optimizers.Adam(), metrics=["accuracy"] )

Results

What the Model Learned

After training on the complete dataset, the model produces a 120-column probability vector for every input image. The Kaggle submission file (full_model_predictions.csv) contains predictions for all 10,357 test images.

Custom image testing across 4 real-world photos revealed an expected spread of results — the clear-cut German Shepherd puppy scored 78.3% confidence, while a mixed-breed dog sniffing the ground stumped the model at ~38% for Silky Terrier. This is entirely expected behaviour: the model predicts based on visual similarity to training images, and ambiguous poses or mixed breeds will naturally produce flatter distributions.

The 78.3% German Shepherd prediction isn't just a number — it's proof the model generalises beyond its training distribution to real-world, uncontrolled photos.

Setup & Usage

Get Running in Minutes

The project runs in a Jupyter notebook. All dependencies are installable via pip.

1. Clone the Repository

git clone https://github.com/yourusername/dog-vision.git cd dog-vision

2. Install Dependencies

pip install tensorflow tensorflow-hub pandas numpy matplotlib

3. Download the Dataset

Download the Kaggle Dog Breed Identification dataset and place the train/ and test/ folders in your project directory.

4. Run the Notebook

jupyter notebook dog_vision.ipynb

Run all cells top-to-bottom. Training will use EarlyStopping automatically. For custom image predictions, update the my_dog_path variable to point to your local image folder.

🐍

Python 3.8+

Compatible with Python 3.8 and above. Tested with TensorFlow 2.x.

💻

GPU Optional

Runs on CPU, but GPU acceleration is strongly recommended for full-dataset training.
